# 超級PUMA語錄王

手機網頁問答遊戲。四個選項，只有一句是沈伯洋在公開場合說過的原話；一局30題（初級、中級、高級各10題），答到60分救回奔奔抱抱。

- 純靜態網頁，無框架、無建置步驟：`index.html`、`style.css`、`app.js`、`config.js`、`data/questions.json`、`img/`、`audio/`。
- 每題的正解照公開影片逐字稿收錄，答完顯示場合、日期與原片連結；其餘三個選項是出題者寫的，不是他說的。
- 計分：初級2分、中級3分、高級5分，滿分100分。排行榜先比分數，同分比解題時間。
- `config.js` 的 `api` 留空時，排行榜只記在玩家自己的裝置上。

本遊戲為民間自製，非競選總部出品。吉祥物「奔奔抱抱」圖像取自競選官網公開素材；場景底圖以生成式模型製作。
